# 🏡 House Price Prediction using Machine Learning

A comprehensive **House Price Prediction** project built using **Python** and Machine Learning techniques. This project focuses on predicting house prices by analyzing property features through data preprocessing, feature engineering, regression modeling, and performance evaluation.

---

## 🚀 Project Overview

This project demonstrates the complete Machine Learning workflow for a regression problem, including data preprocessing, feature scaling, train-test splitting, model training, evaluation, and visualization. The primary objective is to build an accurate predictive model that estimates house prices based on property characteristics.

---

## ✨ Features

- 🏠 Load and explore a housing dataset
- 🧹 Clean and preprocess the data
- ⚙️ Perform feature scaling and categorical encoding
- 📊 Split the dataset into training and testing sets
- 🤖 Train a Machine Learning regression model
- 📈 Evaluate model performance using RMSE and R² Score
- 📉 Visualize prediction results and model performance
